# 设备 / 通道编辑重构 · 设计方案（v2 · 已并入评审决策）

> 目标：编辑粒度统一到「设备」；位置/安装位置只在设备补齐；通道只保留名称 + 通道类型等轻量属性；
> 区划/分组/地图按「设备」添加（自动带入全部通道）。
> 新增「系统配置」一级菜单 + 数据字典，设备类型/通道类型/坐标系/厂商等均由字典驱动、用户可扩展。

---

## 0. 决策回顾（本次评审已定）
1. 设备类型、通道类型 → 建**数据字典表**，系统配置菜单里可维护，下拉关联。
2. 坐标系 → 同样放字典表配置。
3. 监视方位 → 保留为**通道可选字段**（云台看朝向重要）。
4. `channel_ext` 经纬度 → **保留**；设备配好位置后**同步写入该设备所有通道**。
5. 通道类型先做 可见光/热成像/红外/测温/其他，用户可自行加。
6. 地图**拖点取经纬度**回填 —— 要。
7. 添加设备时的**厂商、设备类型**也做成字典，下拉选择。

## 1. 系统字典（新增子系统）

### 1.1 表结构
```sql
-- 字典类型
zws_dict_type(
  id, code VARCHAR(64) UNIQUE,   -- device_type / channel_type / coordinate_system / manufacturer / ...
  name VARCHAR(128),             -- 显示名：设备类型 / 通道类型 / 坐标系 / 厂商
  remark, builtin TINYINT, sort INT, create_time, update_time
)
-- 字典项
zws_dict_item(
  id, type_code VARCHAR(64),     -- 关联 dict_type.code
  value VARCHAR(64),             -- 存库的值（如 thermal / 海康 / WGS84）
  label VARCHAR(128),            -- 显示文本（如 热成像 / 海康威视）
  sort INT, enabled TINYINT, builtin TINYINT, remark, create_time, update_time,
  UNIQUE KEY uk_item (type_code, value)
)
```
- `builtin=1` 的内置项**可停用、不可删**（保护默认枚举）；用户新增项可增删改。

### 1.2 菜单与页面
- 一级菜单「**系统配置**」（跟随现有能力域，建议放「运维管理」下或单独「系统」），子项「**数据字典**」。
- 页面：左侧字典类型列表（设备类型/通道类型/坐标系/厂商…，可新增类型）；右侧该类型的枚举项表格（值/标签/排序/启用/删除），可增删改。

### 1.3 种子数据（builtin）
- `device_type`：球机 / 半球 / 枪机 / 遥控枪机 / 遥控半球 / 多目全景 / 多目分割 / 其他
- `channel_type`：可见光 / 热成像 / 红外 / 测温 / 其他
- `coordinate_system`：WGS84 / CGCS2000 / GCJ02 / BD09
- `manufacturer`：海康 / 大华 / 宇视 / 华为 / 其他

### 1.4 下拉联动
设备新增/编辑、通道类型、坐标系、厂商 → 都按 `type_code` 从字典拉取（`GET /dict/items?type=`），不再硬编码。

## 2. 数据模型调整

### 2.1 设备基本信息（zws_device，稳定）
| 字段 | 处理 |
|---|---|
| name 设备名称 | 可编辑 |
| manufacturer 厂商 | 可编辑，值引用 `manufacturer` 字典；同步探测可预填 |
| model 型号 / firmware 固件 / serial_number 序列号 | 预填（探测）；空可手填 |
| device_type 设备类型 | **新增列**，值引用 `device_type` 字典；空可手选 |
| ip/port/username/password | **只读** |
| protocol/accessMode/gb_code | 只读（GB 国标码维持可编辑，级联用） |

### 2.2 zws_device_ext（位置，设备级唯一来源）
longitude / latitude / address(安装位置) / geo_coord_sys(引用坐标系字典) / remark / tags / extra_json（**结构已存在**，仅去建新不新建）。
保存设备位置时：写 device_ext，并 `UPDATE zws_channel_ext SET lon/lat` 同步到该设备**所有通道**。

### 2.3 zws_channel（通道基本）
- name 可编辑
- **新增** channel_type（值引用 `channel_type` 字典）
- kind/gb_code/external_key 只读

### 2.4 zws_channel_ext
- **保留** longitude/latitude（由设备位置同步写入，不单独编辑）
- **新增** direction（监视方位，可选，GB 方位枚举 1~98；沿用现有枚举常量，不进字典）
- 保留 ptz_type/has_audio/tags/record_plan_id/gb_json/extra_json

### 2.5 迁移
- 新增 `zws_dict_type` / `zws_dict_item` + 种子。
- `zws_device.device_type`、`zws_channel.channel_type`、`zws_channel_ext.direction` 加列。
- 存量通道经纬度回填 device_ext（每设备取首个非空）。

## 3. 接口调整
| 接口 | 变更 |
|---|---|
| `GET /api/v1/dict/types`、`GET /api/v1/dict/items?type=` | 新增：字典类型/项查询（下拉用） |
| `POST/PUT/DELETE /api/v1/dict/...` | 新增：字典类型/项维护（系统配置页） |
| `GET /devices/detail?internalCode=` | 返回 设备基本 + ext(位置) + channels[{id,name,channelType,channelTypeLabel,kind,direction,gbCode,...}] |
| `PUT /devices` | 一次保存：name/manufacturer/model/serialNumber/deviceType + ext{lon,lat,address,geoCoordSys,remark,tags} + channels[{id,name,channelType,direction}]；保存后同步通道经纬度 |
| `POST /common/channel/region|group/device/add` | 复用（按设备挂全部通道） |
| 地图 | 前端「添加设备」，用 device_ext 经纬度；支持拖点取点回填 |

## 4. 页面与交互 / UI

### 4.1 设备列表（/devices）
操作：刷新/同步 · 通道(查看播放云台,无编辑) · 编辑(打开设备编辑抽屉) · 删除。

### 4.2 设备编辑（新，右侧抽屉 ~760px，三页签）
```
[基本信息] [扩展信息(位置)] [通道列表]
基本信息：设备名称(改) / 设备类型(字典下拉) / 厂商(字典下拉) / 型号 / 固件 / 序列号(预填可改) /
          接入方式·协议(只读) / IP·端口(只读) / 用户名(只读) / 密码(只读不展示) / 国标编号(GB可填)
扩展信息(位置)：安装位置(address) / 经度 / 纬度 / 坐标系(字典下拉) / 备注 / 标签 / [地图选点·拖点回填]
通道列表：通道名称(改) | 通道类型(字典下拉 可见光/热成像/…) | 监视方位(可选下拉) | 类型(kind只读) | 国标码(只读) | 状态
底部：[取消] [保存]（一次提交设备+位置+通道；保存后经纬度同步到通道）
```
只读字段灰显 + tooltip「由设备同步，不支持修改」。

### 4.3 通道面板（unified-panel）
去掉「编辑」；保留 播放/云台/回放/抓图；通道信息只读（含通道类型、方位）。

### 4.4 行政区划 / 业务分组
「添加通道」→「**添加设备**」：设备选择弹窗（名称/IP/协议/通道数，多选搜索）→ 调 `region|group/device/add`，带入全部通道；下方列表仍按通道展示。

### 4.5 电子地图
「添加通道」→「**添加设备**」：选设备按经纬度落点，展示全部通道；设备编辑位置页签支持在地图上**拖点取经纬度**回填。

### 4.6 系统配置 → 数据字典
字典类型列表 + 枚项维护（见 1.2）。

## 5. 分阶段实施
- **P1 字典子系统**：两张字典表 + 种子 + 菜单「系统配置/数据字典」+ 增删改查接口与页面。
- **P2 设备编辑重构**：device_type/channel_type/direction 加列；设备编辑抽屉三页签；位置收归设备并同步通道；删除通道编辑页（ChannelEdit/CommonChannelEdit）；unified-panel 去编辑；新增/编辑下拉改字典驱动。
- **P3 区划/分组/地图按设备添加** + 地图拖点取经纬度。

## 6. 影响面/工作量
DB 0.5d · 后端(字典 CRUD + detail/update + channel_type + 同步经纬度) 1.5~2d · 前端(字典页 + 设备编辑抽屉 + 选择器替换 + 地图拖点) 3~3.5d · 联调真机 1d。
