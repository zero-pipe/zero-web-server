# 接口契约统一（Web / zplayer / 第三方共用一套规则）

> 本文是 zero-web-server 对外业务接口（C 族）的**唯一契约**。
> 目标：所有客户端——Web 管理端、zplayer 桌面端、第三方集成——共用**同一套**
> 路径语义、同一套 **ID 口径**、同一套响应结构。旧接口（`/play/*`、顶层
> `/playback/*`、`/common/channel/play|front-end|playback|talk|broadcast`、
> `/front-end/*`、`/playback/cloud/*` 顶层族）**已全部删除**，代码中不再保留第二套语义。

---

## 1. 三条铁律

1. **凡"针对某个通道"的操作，一律走 `/api/v1/resources/{resourceId}/<动作>`。**
2. **resourceId 是唯一主键**：= 通道表 id（数字字符串）= 目录树通道叶节点的 `id`
   字段 = `/channels` 返回的 `resourceId`。**不再用 GB 码对（设备码/通道码）、
   内码对（D…/C…）去拼 URL。** 内码、GB 码只作为展示/协议交互字段，不参与路由。
3. **统一响应信封** `{code,msg,data}`，`code==0` 为成功；鉴权头 `access-token`（JWT，
   非 Bearer）。密码登录时提交 MD5。

Web 与 zplayer 不各自发明 ID / 路径 / 字段——本文件即准。

---

## 2. 身份与目录

### 2.1 目录树（推荐客户端用）

`GET /api/v1/group/tree/list?parent=<组id>&hasChannel=true`

- 根节点不加 `parent`；非空 `parent` 时同时带 `hasChannel=true` 以把通道叶并入。
- 返回数组，元素 `type`：`0`=分组，`1`=通道叶。

通道叶（`type==1`）关键字段：

| 字段 | 含义 | 用途 |
|---|---|---|
| `id` | **resourceId**（数字） | **所有通道操作的路径主键** |
| `internalCode` | 通道内码 `C…` | 展示 / 云端回放内部对查 |
| `deviceInternalCode` | 设备内码 `D…` | 展示 |
| `name` / `status` | 名称 / `ON`·`OFF` | UI |
| `treeId` | 树节点唯一键（如 `channel12`） | 树展开 |
| `parentDeviceId` | 父节点（组织码） | 仅树结构，不用于取流 |

### 2.2 通道列表（分页，管理端用）

`GET /api/v1/channels?page=&count=&query=&protocol=&deviceInternalCode=`

返回 `{list,total,pageNum,pageSize}`，`list[]` 元素含：

`resourceId, internalCode, deviceId, deviceInternalCode, deviceName, protocol,
name, kind, channelType, externalKey, gbCode, status, online, ptzType, direction,
hasAudio, longitude, latitude, mapLevel, tags, enabled, caps[], gb{}`

`caps[]` 是该通道**真实可用**能力（`play/ptz/preset/snapshot/playback/record/...`），
UI 据此点亮按钮。

## 3. 直播

| 动作 | 请求 |
|---|---|
| 起播 | `POST /api/v1/resources/{id}/live/start`，body `{"profileId":""}`（空=主码流） |
| 停播 | `POST /api/v1/resources/{id}/live/stop` |

响应 `data` 为 **StreamContent**（见 §7）。同一资源并发起播在平台侧合并为一次信令，
多人同时点播不会互相踢流。

## 4. 云台 / 预置位 / 镜头

### 4.1 云台

`GET /api/v1/resources/{id}/ptz`

| 参数 | 取值 |
|---|---|
| `command` | `up/down/left/right/upleft/upright/downleft/downright/zoomin/zoomout/stop` |
| `horizonSpeed` | 0–255 |
| `verticalSpeed` | 0–255 |
| `zoomSpeed` | 0–16 |

### 4.2 预置位（presetId 一律为字符串）

| 动作 | 请求 |
|---|---|
| 查询 | `GET /api/v1/resources/{id}/preset/query` → `data:[{presetId,presetName}]` |
| 调用 | `GET /api/v1/resources/{id}/preset/call?presetId=<s>` |
| 设置 | `GET /api/v1/resources/{id}/preset/add?presetId=<s>` |
| 删除 | `GET /api/v1/resources/{id}/preset/delete?presetId=<s>` |

- 国标：presetId 为数字索引（1–255）。
- ONVIF：presetId 为设备分配的 token 字符串。
- 插件（私有 SDK）暂未实现预置位，返回“该接入方式暂不支持预置位”。

### 4.3 其它镜头能力（聚焦/光圈/雨刷/辅助/巡航/扫描）

保留在通用命令族：`POST /api/v1/resources/{id}/command/{cmd}`，body `{"params":{...}}`。
`cmd` 由协议驱动解释，平台不解析参数语义。

## 5. 快照

`GET /api/v1/resources/{id}/snapshot` → 直接返回 JPEG 字节（`image/jpeg`）。

## 6. 回放

### 6.1 设备录像回放（驱动实现 PlaybackDriver 的通道）

| 动作 | 请求 |
|---|---|
| 检索 | `POST /api/v1/resources/{id}/playback/records`，body `{"startTime":"2006-01-02 15:04:05","endTime":"...","streamType":0}` |
| 起播 | `POST /api/v1/resources/{id}/playback/start`，body `{"startTime":"...","endTime":"...","stream":"main\|sub"}` |
| 停播 | `POST /api/v1/resources/{id}/playback/stop` |

### 6.2 云端录像回放（zstorage 旁路 PS 段 / MP4）

| 动作 | 请求 |
|---|---|
| 片段 | `GET /api/v1/resources/{id}/playback/cloud/segments?start=<ms>&end=<ms>` |
| 起播 | `GET /api/v1/resources/{id}/playback/cloud/start?recordId=<id>&startTime=<绝对ms>` |
| 拖动 | `GET /api/v1/resources/{id}/playback/cloud/seek?recordId=<id>&seekTime=<绝对ms>` |
| 停播 | `GET /api/v1/resources/{id}/playback/cloud/stop?recordId=<id>` |

片段元素（`SegmentView`）：

```json
{"recordId":1,"stream":"D..._C...","startTime":1795789873008,"endTime":1795789927060,
 "durationMs":54052,"container":"ps","size":2835256,"online":true}
```

`container`：`ps`（zstorage 槽位段，无需通道即可播放）或 `mp4`。
`start/seek` 用**绝对毫秒**时间；`start` 响应额外含 `duration`（毫秒）。

## 7. StreamContent（直播/回放/云端起播统一响应体）

```json
{"app":"live","stream":"D..._C...","ip":"192.168.1.2",
 "flv":"http://.../live/D..._C....flv","ws_flv":"ws://.../live/D..._C....flv",
 "hls":"http://.../live/D..._C....m3u8","rtmp":"rtmp://.../live/D..._C...",
 "rtsp":"rtsp://.../live/D..._C...","rtc":"...","rtcs":"...",
 "videoCodec":"H264","audioCodec":"AAC","mediaServerId":"..."}
```

播放地址挑选：客户端按传输方式自行选字段（zplayer：`rtsp→rtmp→flv→hls`；
Web 端统一 Jessibuca 走 `flv/ws_flv`）。字段为空表示该协议不可用。

## 8. 认证

| 动作 | 请求 |
|---|---|
| 登录 | `GET /api/v1/user/login?username=&password=<MD5>` → `data:{accessToken,username,serverId}` |
| 登出 | `GET /api/v1/user/logout` |

401 = 登录态失效，客户端回登录页。

## 9. 已删除的旧接口（勿再使用）

- `/api/v1/play/start|stop|broadcast/*`
- `/api/v1/playback/start|stop|pause|resume|speed|seek/*`（顶层）
- `/api/v1/common/channel/play`、`/play/stop`、`/talk/*`、`/broadcast/*`、`/front-end/*`、`/playback/*`
- `/api/v1/front-end/*`（整个族）
- `/api/v1/playback/cloud/segments/{devCode}/{chCode}`、`/channel-segments/{id}`（→ 并入 `resources/{id}/playback/cloud/segments`）

`/api/v1/common/channel/{one,list,add,update,map/*,region/*,group/*,civilcode/*,parent/list,…}`
等**管理类**接口保留（无重复语义），但不属于"通道操作"，客户端播放链路不依赖它们。
