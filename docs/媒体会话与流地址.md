# 媒体会话与流地址规范

> 目标：把“当前有哪些流在跑、从哪来、怎么看/复制直链”收敛到一个**只读运维视图**，
> 取代原来形同 demo 的「推流列表 / 拉流代理」页面，以及各播放器页面下方重复的“网页分享/嵌入代码/直链”面板。
>
> 权威实现：`internal/application/mediasession/`（后端）+ `web/src/views/mediaSession/index.vue`（前端）。
> 流命名规则见 [`../CLAUDE.md`](../CLAUDE.md) 2.1，地址合成复用 `port.MediaEndpoint.StreamPlayURLs`（与点播同源）。

---

## 1. 核心口径：流是“点播的产物”

平台不主动“建立”常驻推拉流。**设备接入协议决定取流来源**，但真正的 `app/stream` 是在用户点播
（`GET /api/v1/play/start/...`）或手动建代理时才落到某个 ZMS 节点上的。因此：

- 媒体会话 = 各在线节点上的**实时流快照**（合并 `media/list`），不是配置表。
- 页面上每个会话的来源由**流名反查**得出，而不是用户在别处“登记”出来的。

| 接入协议 | 典型取流来源 | 会话 `sourceType` | 展示标签 |
|---|---|---|---|
| GB28181 | 平台向设备 INVITE，设备 RTP/PS 推到 ZMS | `gb28181` | `GB28181 · RTP/PS 推流` |
| ONVIF | 平台让 ZMS 用 RTSP 拉设备 | `onvif` | `ONVIF · RTSP 拉流` |
| 插件（私有 SDK） | 插件推 RTP/RTSP/RTMP 到 ZMS | `plugin` | `插件 · <RTP 推流/RTSP 拉流/RTMP>` |
| 其他 | 手动代理、级联进来的流 | `manual` | `手动代理/其他` |

> 反查规则：`live` 应用、流名 `<设备内码>_<通道内码>`（`_playback` / `_download` 会去掉后缀）→
> 用 `D...` / `C...` 内码查资产表拿设备/通道名与接入协议。**非 `live` 应用一律按 `manual` 处理。**

## 2. 页面与接口

菜单：**媒体管理 → 媒体会话**（`/mediaSession`）。原「推流列表(`/push`)」「拉流代理(`/proxy`)」下线。

| 动作 | 接口 | 说明 |
|---|---|---|
| 列表 | `GET /api/v1/media-sessions` | 合并所有在线节点实时流；2~3s 轮询，`silent` 不弹错 |
| 停止 | `POST /api/v1/media-sessions/stop` | body `{nodeId,app,stream}`；走 ZMS `close_stream`，点播会按需重新拉起 |
| 临时代理 | `POST /api/v1/media-sessions/proxy` | body `{nodeId?,app?,stream?,url}`；把外部 RTSP/RTMP/HTTP-FLV 源拉进 ZMS，`app` 缺省 `proxy` |

列表每行关键字段：`app/stream`、`deviceName/channelName`、`sourceType/sourceLabel`、编码/分辨率/帧率、
`bytesSpeed`（码率）、`readerCount`（观看数）、`aliveSecond`（时长）、`mediaServerId`、`addresses`。

## 3. 地址入口：唯一，且只给直链

- 每个会话行**只有**一个入口「地址」(图标 `el-icon-link`)，点击弹窗展示**协议直链列表**。
- 直链由后端 `addresses` 字段直接给出（`flv / ws_flv / hls / rtmp / rtsp / rtc / rtcs`，空值不展示），
  与点播 `streamInfo` 同源，保证“看到的就是能播的”。
- **不再暴露“分享页 / 网页嵌入 iframe”。** 播放器/H5 分享不是产品能力，避免把内网地址、鉴权 token
  以 iframe 形式外泄。需要接入的第三方走「接入鉴权」页签发的接入 token（见 `接口与鉴权规范.md`）。

---

## 5. 何时用「临时代理」

- 第三方只给了一条 RTSP/RTMP/FLV 地址、又不走标准接入（不经 ONVIF/GB/插件）：用「新建临时代理」把它拉进 ZMS，
  之后按 `app/stream` 用直链播放。
- 临时代理是**运维手段**，不进入资产/通道模型；长期接入请走标准接入或插件，享受统一资产与能力声明。
